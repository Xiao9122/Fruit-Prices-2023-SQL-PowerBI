### USDA 2023 Fruit Price Analysis | SQL Server & Power BI

### Project Overview

Analyzed USDA fruit pricing data using Microsoft SQL Server and Power BI to identify price differences across fruit categories and preparations.

### Tools Used
+ DBeaver

+ Microsoft Power BI

+ SQL

### Average Retail Price by Fruit Form

This visualization compares the average retail prices of fruit products across different forms, including fresh, frozen, canned, and dried. The analysis highlights pricing differences between product categories and provides insight into how fruit processing and packaging may influence retail costs.

Purpose: Identify price variations across fruit forms and support data-driven comparisons of fruit retail pricing.
